# Evaluate structural variants

The purpose of this exercise is to visually evaluate existing alignments and identify structural variants. This is done by inspecting BAM files that have been generated for five different samples sequenced via paired-end reads. 


## Visual inspection of each file to determine the kind of variation present.

Reference genome used is at this [link](https://data.biostarhandbook.com/courses/2026-appbio/igv/fasta/ebola-1976.fa)
